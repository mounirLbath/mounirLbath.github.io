Functional Map Bench

Ovsjanikov, Ben-Chen, Solomon, Butscher & Guibas, SIGGRAPH 2012  ·  C = ΦBT MB Π ΦA

What you are looking at. Shape B is a deformation of shape A with the same mesh connectivity, so the correspondence T: A → B is known (vertex i ↔ vertex i). A functional map represents T by how it carries functions: f on A becomes f ∘ T−1 on B. Written in the first k Laplace–Beltrami eigenfunctions of each shape, this is a k × k matrix C. Rows index the basis of B, columns the basis of A. Near-isometric deformations (bending, twisting) give a nearly diagonal C; stretching, bumps and sculpting spread energy off the diagonal and grow with k.

Ground truth uses the known correspondence directly. Estimated follows the 2012 paper: it never sees the correspondence, only descriptor functions (Wave Kernel Signatures, plus a few heat-kernel landmark functions at the yellow points) that should be preserved, C A ≈ B, together with commutativity with the Laplacians, ‖C ΛA − ΛB C‖, solved in least squares row by row. Optional ICP refinement alternates nearest neighbours in the spectral domain with projection onto orthogonal matrices. With no landmarks the near-symmetries of these shapes make the problem ambiguous, which the statistics make visible.

Interacting. Drag to orbit, scroll to zoom. The Move tool translates a shape (drag) or rotates it (Alt + drag); the same rigid motion is available as Pose sliders. Because the Laplace–Beltrami operator is intrinsic, a rigid motion changes neither the eigenbasis nor C, only the coordinate functions you might transfer. The Cat base is a procedural implicit surface extracted with surface nets, so it can be regenerated at any resolution. Move the sliders, or pick the Sculpt tool (or hold Shift) and drag on either surface to pull it; the eigenbases and the map recompute automatically. Hover over a cell C[i, j] of the heatmap to see the two eigenfunctions it relates; click to keep it. In Function transfer mode, click on A to move the bump. Eigenvector signs of B are flipped to match A so that a clean map reads as +1 on the diagonal.
